# ☁️ Weather Fit Suggestion App

This web app lets users enter a city and get:
- The current temperature (via OpenWeatherMap API)
- A fun and casual clothing suggestion based on the weather 🌤️🧥🔥

---

## 🔧 Built With
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

---

## 🚀 How to Use
1. Enter any city (e.g., "Houston")
2. Click **Check Weather**
3. See the temperature and your fit suggestion 😎

---

## 📌 Example Output
> 🌡️ Temp in Houston: 28°C  
> 😎 It’s warm. Light jacket or hoodie.
